# QuickJump
**This README covers installation, usage, and licensing.**    

## Installation 
To install, download the latest release's zip/tar and uncompress. 
Then, go to chrome://extensions and toggle Dev Mode (Might be blocked due to workspace restrictions)    
Click 'Load Unpacked' and select the uncompressed version of QuickJump you downloaded.   
Optional: Pin the extension.    

## Usage    
By defualt, you have ZERO extensions. However, you can create a new one by clicking the gear icon and all of a sudden, you will see a popup.     
That should prompt you for Name of shortcut, actual url, and finally extra info.    
To use, go to the extension (click on icon) and select the shortcut. It should load   
Or extra, go to google.com, search up the name of your extension (fuzzy searching ready!) and it should pop up in the left bottom part of the screen. 
Click the reccomendation(s) you see and boom, opens a new tab and takes you there.
